# DB Browser for SQLCipher 4.0.0

DB Browser for SQLCipher 4.0.0 is the first Windows-only release from the v4
upgrade line. It targets Windows x64 and uses SQLCipher for encrypted SQLite
database support.

## Supported environment

- Windows 10 or Windows 11, x64
- Visual Studio 2022/MSVC v143 build output
- Windows SDK 10.0.26100.0
- Qt 6.11.1 (`msvc2022_64`)

The packages require a compatible Microsoft Visual C++ x64 Runtime. It is not
bundled or installed by either package. Download the current supported x64
runtime from Microsoft:

<https://aka.ms/vc14/vc_redist.x64.exe>

## Packages

The GitHub Release contains two user package formats and one SHA-256 file for
each package:

- `DB.Browser.for.SQLCipher-4.0.0-win-x64-portable.exe`
- `DB.Browser.for.SQLCipher-4.0.0-win-x64.msi`

The portable SFX prompts for a new or empty extraction directory and does not
register an installed product. The MSI installs the application per-machine and
allows the Start Menu and desktop shortcuts to be enabled independently.

The packages are not Authenticode-signed. Windows can display an unknown
publisher or SmartScreen warning. Verify the downloaded package against its
adjacent `.sha256` file before running it.

## Build and validation

The release is rebuilt by GitHub Actions from the tagged commit. The workflow
builds all pinned dependencies, runs dependency checks and application unit
tests, validates the strict runtime under a restricted `PATH`, verifies the
portable extraction and MSI administrative image, checks both package hashes,
and creates a Draft Release for manual approval.

Automatic update checks against the upstream DB Browser for SQLite release
endpoint are disabled in this SQLCipher-only build. Automatic WinGet publication
is also disabled because this fork does not use the upstream package identity.

For reproduction steps, see the
[Windows v4 build guide](../windows-v4-build-guide.md).
